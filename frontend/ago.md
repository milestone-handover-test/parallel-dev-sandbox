# 経過した時間の表示

画面に投稿の時刻を出す前に、経過した秒数を「3 分前」のような表示用の文字列に整える。契約 (contract/) は変えない。

## 表示用に整える決まり

経過した秒数は、画面に出す前に `format_ago` (`frontend/format-ago.sh`) で整える。上から順に当てる。

1. 受け付けるのは「先頭に `-` が 0 か 1 個 + 半角の数字 1 個以上」だけ。それ以外は弾く (下の「弾く入力」)
2. 先頭の 0 を外す (`0090` → `90`)。0 だけが並んでいたら `0` にする (`000` → `0`)
3. `-0` は `0` にする (`-0` / `-000` → `0 秒前`)。それ以外のマイナスの数は弾く
4. 64 bit の整数に収まらない数 (`9223372036854775808` 以上) は弾く
5. 一番大きい単位で出し、半端は切り捨てる

| 経過した秒数 | 出す文字列 | 例 |
|---|---|---|
| 0〜59 | N 秒前 | `59` → `59 秒前` |
| 60〜3599 | N 分前 | `90` → `1 分前` |
| 3600〜86399 | N 時間前 | `7200` → `2 時間前` |
| 86400〜31535999 (1〜364 日) | N 日前 | `31535999` → `364 日前` |
| 31536000 (365 日) 以上 | N 年前 | `63072000` → `2 年前` |

- 1 年は 365 日として数える。うるう年は数えない。「N か月前」は出さない (1 か月の長さが決まっていないため)
- 64 bit の整数の最大値 `9223372036854775807` までは整える (`292471208677 年前`)

## 弾く入力

次の入力は、標準出力に何も出さず、標準エラーに理由の 1 行を出して rc 2 で終わる。理由が違えば文言も分ける。

`format_ago: 整数ではない`

- 空
- 文字を含む (`abc` / `12a4`)
- 小数 (`1.5`)
- `+` の付いた数 (`+123`)
- 前後に空白がある (` 12` / `12 `)。整える前に呼ぶ側で落とす
- `-` だけ、`-` が 2 つ以上 (`--1`)、数字の間の `-` (`1-2`)
- 全角の数字 (`１２３`)
- マイナスで整数でない物 (`-1.5` / `-abc`)。整数かどうかを先に見るので「マイナスの数」にはならない

`format_ago: マイナスの数 (未来の時刻)`

- `-` + 数字で、0 でない数 (`-1` / `-90` / `-0090`)
- 64 bit に収まらないマイナスの数 (`-99999999999999999999`) もこちら。符号を先に見る

`format_ago: 大きすぎる数`

- 64 bit の整数に収まらない数 (`9223372036854775808` / `99999999999999999999`)。整数ではあるので「整数ではない」とは分ける

入力は `[` や `$(( ))` に渡す前に文字列のまま確かめるので、入力の中のコマンド (`a[$(…)]` など) は走らない。

## 確かめ方

`bash frontend/test-format-ago.sh` (全部通れば rc 0)
