# 件数の表示

画面に件数 (例: いいねの数) を出す前に、表示用の文字列に整える。契約 (contract/) は変えない。

## 表示用に整える決まり

件数は、画面に出す前に `format_count` (`frontend/format-count.sh`) で整える。上から順に当てる。

1. 受け付けるのは「先頭に `-` が 0 か 1 個 + 半角の数字 1 個以上」だけ。それ以外は弾く (下の「弾く入力」)
2. 先頭の 0 を外す (`007` → `7`、`0007` → `7`)。0 だけが並んでいたら `0` にする (`000` → `0`)
3. `-0` は `0` にする (`-0` / `-000` → `0`)
4. 右から 3 桁ごとにカンマを入れる (`1234567` → `1,234,567`、`-1234` → `-1,234`)。3 桁以下はカンマを入れない (`999` → `999`、`-123` → `-123`)

- 大きい数は縮めず、カンマのまま全部出す (`12345678901234567890123` → `12,345,678,901,234,567,890,123`)。「1.2万」のように縮めたり、「9,999+」のように上限で止めたりしない
- 数として計算せず文字列のまま区切るので、64 bit の整数に収まらない数でも桁を落とさない

## 弾く入力

次の入力は、標準出力に何も出さず、標準エラーに `format_count: 整数ではない` の 1 行を出して rc 2 で終わる。

- 空
- 文字を含む (`abc` / `12a4`)
- 小数 (`1234.5`)
- `+` の付いた数 (`+123`)
- 前後に空白がある (` 12` / `12 `)。整える前に呼ぶ側で落とす
- `-` だけ、`-` が 2 つ以上 (`--1`)、数字の間の `-` (`1-2`)
- 全角の数字 (`１２３`)

## 確かめ方

`bash frontend/test-format-count.sh` (全部通れば rc 0)
